# 탑뷰 D&D 스타일 RPG - Godot 스타터

설명
- Godot 4 기반의 간단한 탑뷰 RPG 스타터 템플릿입니다.
- 플레이어 이동 스크립트(player.gd)와 주사위 유틸(dice.gd)을 포함합니다.

빠른 시작
1. Godot 4에서 프로젝트 열기
2. Input Map에 move_up/move_down/move_left/move_right를 등록 (WASD 또는 화살표)
3. scenes/main.tscn을 메인 씬으로 열고 테스트

다음 작업(예정)
- 턴 기반 전투 루프 추가
- 적(Enemy) 씬 및 AI
- 인벤토리/스킬/주사위 판정 GUI
